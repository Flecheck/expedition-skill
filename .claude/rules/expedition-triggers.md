# For a manager acts on

Four moments, each with the one duty it fires. **Every duty here is a manager's own**, and a worker
reading them acts on none of them.

- **A node resolves**, so its retrospective is filed in the same edit that writes its answer.
- **A node finishes**, so the frontier is looked at and a replacement is started before anything else
  continues.
- **An agent hands something back for the human**, so it goes in front of them as soon as nothing else
  is.
- **The human should have one thing to do**, if the human has nothing to do and there is a question/gate, give it to him. Wait for him to answer before giving him a question

## Where every other rule lives

The instruction on how to behave and how to use the map are in `/expedition` and next to it `graph-conventions.md`

Every other rule an effort works under is in its map — `.scratch/<effort>/map.md` and the files beside
it. **This file holds triggers only, and overrides nothing there.**

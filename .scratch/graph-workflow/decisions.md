detail it holds. A decision lives in exactly one place, its node; this file never restates one.

new line of its own. Nothing is ever deleted or rewritten.

- [Relay protocol](nodes/08-relay-protocol.md) — prototyped live with two HITL subagents. Routing turned out nearly free; the **payload** is the hard part. Answers go back **verbatim** with provenance and an explicit divergence marker. Death is detected lazily by a failed resume, recovered by replaying an at-relay-time log on the node file, capped at two respawns. All four human redirects are supported; "you decide" is answered by the subagent, "ask me later" stores progress and returns the node to `open` with its answers banked. The manager never answers anything.

- [Done-ness and termination](nodes/10-done-ness.md) — done is a **fixed point the human declares**, never the manager: an empty frontier (where `superseded` ≠ `resolved`, and a parked node is `open`, so "ask me later" postpones *done* and not just the question), a tree meeting the standing bar, a whole-graph **sweep** that produces nothing new, and the human having read the **completion report**. The bar ships as default *properties* — builds, no warnings, formatted, tests pass where relevant, plus project criteria, plus the acceptance condition — with commands **discovered per repo**, since the workflow will run on repos this machine has never seen; the independent reviewer checks it at every implementation node, so "landed" means "landed green". Flags cost nothing until the report, where the human settles them or **postpones** one, which creates a node. No audit agent for cascade misses: the bar, the mechanical edge check, and the human's own reading of the changes are the backstops, and a semantic miss in code that builds cleanly is the named residual risk. ~~**Most efforts never terminate at all, and that is a legitimate steady state.**~~ (the frequency is withdrawn at [node 86](nodes/86-most-efforts-never-end-rejected.md); what stands is that a never-emptying frontier is a legitimate steady state rather than a stalled one)

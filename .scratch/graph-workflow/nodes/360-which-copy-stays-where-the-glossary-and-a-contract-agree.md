Type: grilling
Status: claimed

Q1. Which copy keeps the rule
ASK:           For each of the nine pairs, which copy keeps the rule: the contract section, with the glossary entry cut to what the term means; or the glossary entry, with the contract passage cut to a pointer at the entry?
RECOMMENDED:   The contract keeps the rule and the glossary keeps the meaning. Each glossary entry drops its rule sentences and keeps its definition and its `_Avoid_` line. Each contract passage drops only the sentences that just define the term, which is mainly the first two paragraphs of `## Starting an effort` and the dead-attempt bullet's first two sentences. Four things support this. The contract already wins where the two differ. The rules sit where the manager acts on them. The glossary has no headings for rule 6 to point at. The glossary also describes itself as definitions. Estimated saving: about 400 to 450 words, mostly in the glossary, and the contract sections stay whole.
ALTERNATIVES:  - The glossary keeps the rule, and each contract passage becomes a pointer to the entry. This saves a similar amount. But the manager then reads its rules in a file with no headings, and the contract's precedence clause would point the wrong way.
               - Decide pair by pair, keeping whichever copy is longer or better worded. This needs nine separate judgements, and nothing stops the next new term from drifting.
               - Change nothing, and accept the duplication as the cost of a glossary that can be read on its own.

Q2. Whether this becomes a standing rule
CONTEXT:       The same drift will come back with every new term unless something says where a rule about a term belongs. Under the map, a rule reaches a shipped file only where you say so.
ASK:           Should the answer to Q1 also be written as a standing rule, and if so, where?
RECOMMENDED:   Yes, as one sentence in the glossary's opening, which already states the glossary's rules for what gets in ("A term is added only once a node has settled it."). An example sentence, for the Q1 recommendation: "An entry says what the term means; a rule about the term is stated in the contract section that acts on it, and not here." A rule placed in the glossary is read by every manager on every effort. A rule placed in map.md dies with this effort.
ALTERNATIVES:  - Write it only as a rule in this effort's map.md. It then binds only this effort, and the next effort's new terms can drift again.
               - Make only the one-off cuts to the nine pairs, with no rule.
               - Add it to rule 6 in map.md next to node 367's pointer sentences. Rule 6 is about pointers, and this rule is about where a rule belongs, so it does not fit there cleanly.

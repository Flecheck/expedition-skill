# State in the map what a number handed to another agent must carry

Type: implementation
Status: open

Blocked by: none

## Question

*Surfaced by [Nothing measures the record about itself](183-nothing-measures-the-record-about-itself.md)'s
worker, and pasted as it wrote it.*

> Five recorded numbers on this effort have gone stale and misled the worker that received
>   them, in a spawn, an acceptance condition, a projection, an index line and this node's own spawn. The
>   human settled the rule: a number handed onward carries its date and is said plainly not to be relied
>   on, and its reader measures rather than trusts. Write that rule where the parties that hand numbers
>   onward will meet it.

**Blockers, in the worker's words:** none.

## Acceptance condition

*Written by node 183's worker. Pasted as it wrote it, and not the manager's.*

  The work is `.scratch/graph-workflow/map.md` and
  `.scratch/graph-workflow/map-implementation-rules.md`.

  Done means every one of the following is true of the finished tree.

  1. `.scratch/graph-workflow/map.md` carries, as one item under `## Notes`, a rule stating all three
     of: that a number about the record written into a spawn, a report, a node's question or an
     acceptance condition carries the date it was derived; that it is marked in that text as not
     authoritative and for scale only; and that the party receiving it re-derives the value rather than
     relying on the one given.
  2. That item states, as its ground, that the harm is not the number being approximate but its reader
     not knowing it may have moved.
  3. `.scratch/graph-workflow/map-implementation-rules.md` states the same rule for the writer of an
     acceptance condition: a condition quoting a number about the record dates it, marks it for scale
     only, and does not make the work's correctness depend on that number still holding.
  4. Neither statement forbids giving a number. A statement that a number may not appear in a spawn or
     a condition fails this clause.
  5. Where either file's existing text is replaced rather than added to, the replaced text is appended
     verbatim to `.scratch/graph-workflow/map-history.md` under the heading mirroring the section it
     came from, with any struck-through text left struck through.
  6. No file under `.claude/` is modified, and no file under `.scratch/graph-workflow/nodes/` is
     modified.
  7. The tree meets the bar.

## The manager's note at filing
